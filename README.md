## Project Description

**JavaScript Learning Modules** is a comprehensive, production-grade programming curriculum and code learning repository engineered to guide learners from fundamental computing principles to modern full-stack application development. Built on modern **ECMAScript (ES2023+)** and the high-performance **Node.js** runtime, this curriculum systematically explores the multifaceted nature of JavaScript: syntactic primitives, memory models, first-class functions, closures, prototypal and class-based Object-Oriented Programming (OOP), standard library objects, defensive error handling, modular architectures (ESM and CommonJS), Document Object Model (DOM) and Browser Web APIs, asynchronous concurrency pipelines, backend web services with Express 5, classical data structures and algorithms, application security safeguards, and practical capstone systems.

The repository is architected around **300 self-contained, standalone single-file JavaScript programs** structured into **18 pedagogical modules**. Every single lesson isolates a concrete language mechanism, algorithmic pattern, or architectural technique without burdensome boilerplate or convoluted project configurations. Every file is executable directly via `node <filename>.js` and features informative Indonesian educational inline commentary clarifying every critical line of code. Furthermore, each lesson includes an authentic terminal execution screenshot captured under its module's `output/` directory, allowing learners to verify their local execution results directly against known baselines.

Whether you are a newcomer building foundational programming intuition, a frontend specialist mastering core JavaScript mechanics without framework abstraction, or an experienced engineer transitioning from Python, Java, or C++, this repository provides a rigorous, transparent, and verifiable path toward modern JavaScript mastery.

## Learning Objectives

Upon completing this curriculum, learners will have developed concrete, verified proficiencies across four distinct pedagogical tiers:

### Tier 1: Core Syntax, Data Primitives, and Imperative Control Flow
- Master JavaScript program anatomy, developer console methods (`log`, `warn`, `error`, `table`), semicolon insertion rules (ASI), case sensitivity, and strict mode (`"use strict"`).
- Grasp variable declarations (`var`, `let`, `const`), temporal dead zones (TDZ), lexical block scoping, and dynamic type mutations.
- Differentiate primitive types (`Number`, `BigInt`, `String`, `Boolean`, `Undefined`, `Null`, `Symbol`), arbitrary-precision math, and runtime inspection with `typeof`.
- Implement arithmetic, assignment, relational, and boolean logic, mastering strict equality (`===`), type coercion, ternary operators, nullish coalescing (`??`), and optional chaining (`?.`).
- Construct branch control workflows with `if...else`, multi-condition ladders, switch statements, and short-circuit evaluations.
- Build multi-tier iterative workflows with `for`, `while`, `do...while`, `for...of`, `for...in`, nested matrix traversals, loop counters, and break/continue statements.
- Modularize logic with function declarations, expressions, concise ES6 arrow functions, default/rest parameters, closures, recursion, and immediately invoked function expressions (IIFE).

### Tier 2: Data Structures, Object-Oriented Design, and Functional Paradigms
- Manipulate arrays using mutators (`push`, `pop`, `shift`, `unshift`, `splice`), accessors (`slice`, `concat`), and functional iterators (`map`, `filter`, `reduce`, `find`, `some`, `every`, `sort`, `flat`).
- Perform string manipulations, substring slicing, pattern replacements, template literal interpolations, and text validation.
- Model complex domain entities with object literals, dynamic computed properties, destructuring, shallow/deep copying, and property mutability controls (`Object.freeze`, `Object.seal`).
- Utilize modern keyed collections (`Map`, `Set`, `WeakMap`, `WeakSet`) for high-efficiency lookups and garbage-collection-friendly caching.
- Implement advanced functional programming techniques: currying, function composition, partial application, memoization, and custom generator functions with the Iterator Protocol.
- Demystify runtime execution context and dynamic `this` binding (`call`, `apply`, `bind`), constructor functions, and prototype chain inheritance.
- Architect class-based hierarchies using ES6 classes, constructor initialization, instance/static methods, private fields (`#`), inheritance (`extends`), and runtime polymorphism.

### Tier 3: Built-in Objects, Robustness, Tooling, and Browser Architecture
- Harness standard library objects: `Math`, `Number`, `BigInt`, `Date`, Regular Expressions (`RegExp`), JSON parsing/serialization, `Proxy`, `Reflect`, and `structuredClone()`.
- Implement resilient error handling workflows using `try...catch...finally`, custom `Error` classes, error propagation, stack trace analysis, and invariant assertions.
- Manage modular codebases using ECMAScript Modules (`import`/`export`, named, default, dynamic imports) and Node.js CommonJS (`require`/`module.exports`).
- Configure development manifests (`package.json`), automate tasks via npm scripts, manage dependencies, and apply static code analysis (`ESLint`, `Prettier`).
- Traverse and manipulate Document Object Model (DOM) trees (`querySelector`, `textContent`, `innerHTML`, `classList`, `style`, `createElement`, `appendChild`).
- Handle browser interactions through event listeners, event bubbling, event delegation, client-side form validation, and storage APIs (`localStorage`, `sessionStorage`, History, URL).

### Tier 4: Concurrency, Backend Services, Algorithms, and Capstone Systems
- Dissect asynchronous concurrency mechanics: call stack, task queue, microtask queue, and the JavaScript Event Loop.
- Coordinate asynchronous workflows using `Promise` pipelines (`then`, `catch`, `all`, `allSettled`, `race`), `async/await`, Fetch API, and `AbortController`.
- Engineer backend Node.js solutions utilizing the core `process`, `fs` (File System), `path`, `os`, `events` (EventEmitter), `stream`, `buffer`, and `crypto` modules.
- Build scalable backend HTTP web services and JSON RESTful APIs using the modern **Express 5** framework with route controllers and custom middleware.
- Implement classical computer science algorithms (Linear Search, Binary Search, Bubble/Selection/Insertion/Merge/Quick Sort) and fundamental data structures (Stack, Queue, Linked List, Binary Tree, Graph BFS/DFS, Dynamic Programming).
- Implement application security defenses including Cross-Site Scripting (XSS) mitigation, input sanitization, and defensive data validation.
- Develop 12 end-to-end practical capstone applications ranging from interactive CLI tools to real-time WebSocket messaging systems and full-stack controllers.

## Prerequisites

To run and experiment with the code examples in this repository, ensure your environment meets the following baseline requirements:

- **Node.js Runtime:** **Node.js 20+ LTS** (or Node.js 18+ LTS) is recommended. The repository has been verified on Node.js v26 LTS. Node.js includes the V8 JavaScript engine necessary to execute all 300 lessons standalone.
- **Package Manager:** **npm** (v9.x, v10+, or bundled with your Node.js distribution) for installing optional dependencies used in backend and networking lessons.
- **Command-Line Environment:** Terminal shell such as PowerShell, Command Prompt (cmd), Bash, or Zsh.
- **Code Editor / IDE:** Any modern code editor supporting JavaScript syntax highlighting (Visual Studio Code, WebStorm, Sublime Text, or similar).
- **Prior Experience:** No prior programming or JavaScript experience is required. The curriculum starts from the absolute fundamentals (`console.log`) and progresses step-by-step.

## Getting Started

Follow these steps to set up your local development environment and run your first JavaScript lesson:

### 1. Clone the Repository
```bash
git clone https://github.com/weztcy/JavaScript-Learning-Modules.git
cd "JavaScript-Learning-Modules"
```

### 2. Verify Node.js and npm Installation
Verify that Node.js and npm are properly registered in your system's `PATH`:
```bash
node -v
npm -v
```
*(Expected output: `v20.x.x` or later for Node.js, and `9.x.x` or later for npm)*

### 3. Install Optional Dependencies
Modules 16 and 18 utilize `express`, `ws`, and `puppeteer-core` for server-side networking and project simulations:
```bash
npm install
```

### 4. Execute Your First Lesson
Run the first fundamental lesson directly from your terminal:
```bash
cd module-01-pengenalan-javascript-dan-struktur-program
node 01_hello_world.js
```

## How to Use This Repository

To maximize conceptual understanding and practical mastery, follow this recommended six-step study workflow for each subtopic:

```
[Select Module] ──> [Study Theory & README] ──> [Inspect Source Code]
                                                       │
                                                       ▼
[Experiment & Modify] <── [Compare with Output/ PNG] <── [Execute Program]
```

1. **Select a Module:** Begin with Module 01 if you are new to programming, or jump directly to targeted modules (such as Module 09 for Functional Concepts, Module 14 for DOM, or Module 16 for Node.js Backend) based on your learning goals.
2. **Review the Module README:** Read the dedicated `README.md` inside each module folder for a conceptual overview, learning objectives, and curriculum index.
3. **Inspect the Source Code:** Open the corresponding `.js` file in your editor. Each file is designed to be self-explanatory, featuring educational comments that explain language nuances and structural design.
4. **Execute the Code:** Run the file in your terminal using `node <filename>.js`.
5. **Verify Against Execution Screenshots:** Compare your console output against the verified capture in `output/<filename>.png` to ensure expected behavior.
6. **Experiment and Modify:** Tweak inputs, alter control flow, trigger edge cases, and test hypotheses to solidify your mental model.

## Troubleshooting

Common environment issues and their verified solutions:

### 1. `'node' is not recognized as an internal or external command`
- **Cause:** Node.js is not installed or its binary path has not been added to your system's `PATH` environment variable.
- **Fix:** Download and install the latest LTS release from [nodejs.org](https://nodejs.org/). During installation, verify that the "Add to PATH" checkbox is checked, then restart your terminal.

### 2. PowerShell Execution Policy Error with `npm`
- **Cause:** Windows PowerShell restricts running script files (`npm.ps1`) under default restrictive execution policies (`UnauthorizedAccess`).
- **Fix:** Execute `npm.cmd` explicitly (e.g., `npm.cmd install` or `npm.cmd -v`), or set the execution policy for your current user:
  ```powershell
  Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
  ```

### 3. `Error: Cannot find module 'express'` or `Cannot find module 'ws'`
- **Cause:** Optional npm packages have not been installed in the repository root directory before executing Module 16 or 18 server lessons.
- **Fix:** Navigate to the repository root directory and install dependencies:
  ```bash
  cd "JavaScript-Learning-Modules"
  npm install
  ```

### 4. Special Characters or Emojis Not Rendering on Windows Console
- **Cause:** Default Windows Command Prompt code page (CP1252 or OEM 437) does not render UTF-8 characters properly.
- **Fix:** Switch your console code page to UTF-8 before running lessons:
  ```powershell
  chcp 65001
  ```

### 5. `SyntaxError: Unexpected token '?.'` or `'??'`
- **Cause:** Running lessons on an outdated Node.js runtime (earlier than Node.js 14) that lacks support for optional chaining or nullish coalescing.
- **Fix:** Verify your Node.js runtime with `node -v` and update to **Node.js 20+ LTS**.
